# The files Lore cannot do without at run time, as they lie beside Lore.exe.
#
# This is the one list. It is read in three places, so that none of them can drift:
#   - scripts\build-portable.ps1 refuses a published build that lacks any of them;
#   - Lore itself checks them when it starts (Services\InstalledFiles.cs) and says in
#     the status bar which are missing, rather than carrying on with a reading quietly
#     switched off;
#   - the tests check that each one that comes from the repository is there to be
#     copied, and that Lore.csproj does copy it.
#
# One path to a line. "publish:" marks a file that only a published (self-contained)
# build has; a development build is not expected to. Add a line here when Lore gains a
# file it needs.
